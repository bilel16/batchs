Respiration horizontale Espacer les éléments avec des séparateurs visuels plutôt que de tout coller. L'œil se repose entre les blocs d'information.
Avatar utilisateur Un cercle avec les initiales remplace le texte brut du nom. Permet d'ajouter un menu dropdown (profil, paramètres) en un clic futur.
Fond blanc topbar Contraste plus doux. Le fond vert peut rester pour la sidebar uniquement, créant une identité visuelle claire gauche/haut.
Pill contextuelle L'agence et le code regroupés dans un seul composant "pill" réduisent le bruit visuel et forment une unité logique.

Recommandations d'Implémentation CSS/Angular

Modifications ciblées à apporter dans les fichiers existants du projet.

layout.scss — Variables globales Ajouter les custom properties CSS en haut de src/assets/layout/styles/layout/layout.scss : --surface-card: #fff; --border-radius: 10px; --shadow-card: 0 4px 12px rgba(0,0,0,.1);
app.topbar.component.css Remplacer le fond dégradé vert par background: #fff; border-bottom: 1px solid #e5e7eb; box-shadow: 0 2px 8px rgba(0,0,0,.06);
app.sidebar / app.menuitem Ajouter border-radius: 8px; margin: 2px 8px; aux items du menu. Utiliser transition: background .15s pour les états hover.
theme.css — Ajustement primaire Modifier --primary-color de #4CAF50 à #22c55e et --primary-color-text en #fff. Tous les composants PrimeNG s'adapteront automatiquement.
styles.css — Body & Background body { background: #f1f5f9; } à la place du gris actuel pour un fond légèrement bleuté plus moderne.
p-table global Dans styles.css : .p-datatable .p-datatable-header { border-radius: 10px 10px 0 0; } et .p-datatable tbody tr:hover { background: #f0fdf4 !important; }
p-card — Uniformité ::ng-deep .p-card { border-radius: 12px !important; box-shadow: 0 4px 12px rgba(0,0,0,.08) !important; } dans styles.css pour toutes les cartes.
Polices Ajouter dans index.html : <link rel="preconnect" href="https://fonts.googleapis.com"><link href="...Inter:wght@400;500;600;700;800"> puis --font-family: 'Inter', 'Segoe UI', sans-serif; dans le thème.
Ordre de priorité suggéré :
1. Corriger la typographie (police Inter + tailles) — impact immédiat, 30 min
2. Ajuster le topbar (fond blanc + spacing) — 1h
3. Améliorer la sidebar (icônes + groupes) — 2h
4. Uniformiser les cartes et tableaux via styles.css globaux — 1h
5. Moderniser les formulaires (sections + focus ring) — 2-4h par composant
6. Ajouter les badges de statut dans p-table — 1h
Aucun de ces changements ne modifie la logique métier, les routes, ou les services Angular.
