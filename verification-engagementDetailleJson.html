private EngagementDetailleDto buildEngagementDetaille(Caneva caneva) {
    Long numSeqPers = caneva.getNumSeqpers().longValue();

    // ❌ BUG 1 : cherche les associés dont numSeqPers = numSeqPers du CANVAS PRINCIPAL
    // Ce n'est pas la bonne colonne — numSeqPers dans Associe = son propre numéro bancaire
    List<EngagementPartieDto> actionnaires = associeRepository
            .findAssociesByNumSeqPers(numSeqPers)   // ← MAUVAIS CRITÈRE
            .stream()
            .map(this::associeToEngagementPartie)
            .collect(Collectors.toList());

    // ⚠️ BUG 2 : findByNumSeqpers peut retourner le mauvais ClientCanvas
    // si plusieurs canvas pour le même client (pas de lien caneva_id)
    EngagementPartieDto premierResponsable = clientCanvasRepository
            .findByNumSeqpers(numSeqPers)            // ← AMBIGU sans canevaId
            .map(this::clientCanvasToPremierResp)
            .orElse(null);

    // ⚠️ BUG 3 : distinct() sur des entités JPA sans equals()/hashCode()
    // peut dupliquer les vendeurs — Vendeur.numseqpers est Integer, pas Long
    List<EngagementPartieDto> vendeurs = caneva.getCreditAchatTerrains().stream()
            .flatMap(cat -> cat.getVendeurs().stream())
            .filter(v -> v.getNumseqpers() != null)
            .distinct()                               // ← NON FIABLE sans equals()
            .map(this::vendeurToEngagementPartie)
            .collect(Collectors.toList());

    return EngagementDetailleDto.builder()
            .actionnaires(actionnaires)
            .premierResponsable(premierResponsable)
            .vendeurs(vendeurs)
            .groupe(List.of())   // ← groupe jamais rempli
            .build();
}

4 bugs identifiés — tableau de synthèse

#PartieSévéritéProblème exactEffet constatéCorrection
B1 Actionnaires CRITIQUE findAssociesByNumSeqPers(caneva.numSeqpers)
cherche les associés dont leur propre num_seq_pers = numSeqPers du canvas.
Mais dans la table associe, il n'y a pas de colonne caneva_id → impossible de retrouver les actionnaires d'un canvas précis. 		La liste des actionnaires est toujours vide (0 résultats) ou contient les mauvaises personnes. Ajouter un champ canevaId dans Associe.java + migration SQL + nouvelle requête findByCanevaId().
B2 Premier Responsable MAJEUR findByNumSeqpers(numSeqPers) utilise Optional.findFirst().
Si un client a créé plusieurs canvas, on récupère le premier ClientCanvas trouvé (ordre indéterminé) — pas forcément celui lié au canvas courant. 		Le 1er responsable peut appartenir à un autre canvas du même client. Ajouter canevaId à ClientCanvas.java + migration SQL + requête findByNumSeqpersAndCanevaId().
B3 Vendeurs MAJEUR .distinct() sur des entités JPA sans equals()/hashCode() définis → chaque objet est considéré unique par référence → doublons si un vendeur est dans plusieurs crédits achat terrain.
De plus, Vendeur.numseqpers est Integer mais vendeurToEngagementPartie() cast en Long → erreur potential de conversion. 		Vendeurs en double dans le JSON. Potentiel crash si numseqpers = null. Remplacer .distinct() par déduplication via Map<Integer, Vendeur> sur numseqpers.
B4 classeBCT manquant MINEUR Dans associeToEngagementPartie(), clientCanvasToPremierResp() et vendeurToEngagementPartie() : seule classeBNA est chargée. classeBCT n'est jamais chargée malgré l'existence de EngagementPartieDto.classeBCT. L'onglet "Classe BCT" des parties liées est toujours vide dans le snapshot. Appeler loadClasseBCTSafe() dans les 3 méthodes de conversion.

private EngagementPartieDto vendeurToEngagementPartie(Vendeur vendeur) {
    // ✅ Null-safe : numseqpers est Integer, conversion sécurisée
    String numSeqPersStr = vendeur.getNumseqpers() != null
            ? String.valueOf(vendeur.getNumseqpers()) : null;

    if (numSeqPersStr == null) {
        // Vendeur sans numSeqPers bancaire : on retourne sans engagement
        return EngagementPartieDto.builder()
                .typePartie("VENDEUR")
                .nom(vendeur.getNomPrenom())
                .numSeqPers(null)
                .engagementsBNA(List.of())
                .engagementsBCT(List.of())
                .classeBNA(List.of())
                .classeBCT(List.of())   // ✅ ajouté
                .build();
    }

    EngagementDTO eng      = loadEngagementSafe(numSeqPersStr);
    List<ClasseDTO> bna    = loadClasseBNASafe(numSeqPersStr);
    List<ClasseDTO> bct    = loadClasseBCTSafe(numSeqPersStr);  // ✅ ajouté

    return EngagementPartieDto.builder()
            .typePartie("VENDEUR")
            .nom(vendeur.getNomPrenom())
            .numSeqPers(vendeur.getNumseqpers() != null
                    ? vendeur.getNumseqpers().longValue() : null)
            .engagementsBNA(eng.getListeEngagementBNA())
            .engagementsBCT(eng.getListeEngagementBCT())
            .classeBNA(bna)
            .classeBCT(bct)   // ✅ ajouté
            .build();
}

       CASE
           WHEN DONNEES_ENGAGEMENT_DETAILLE_JSON IS NULL THEN 'NULL'
           WHEN DBMS_LOB.GETLENGTH(DONNEES_ENGAGEMENT_DETAILLE_JSON) = 0 THEN 'VIDE'
