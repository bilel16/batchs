🟢 Services Java Backend — Spring Boot
Architecture Spring Boot Chaque service est annoté @Service, injecté via @RequiredArgsConstructor (Lombok). Les services transactionnels utilisent @Transactional(propagation = REQUIRES_NEW) pour garantir l'atomicité snapshot + log. Les interfaces (IEngagementService, IClientService, etc.) encapsulent les appels vers Oracle SAEB.
📸

🟣 Services Externes — Oracle SAEB (Données Banque)
Architecture externe Ces 4 interfaces Spring lisent les données depuis le système Oracle SAEB de la BNA (base historique). Chaque méthode est entourée d'un try/catch dans les services appelants — si Oracle SAEB est indisponible, le système continue avec des listes vides (pattern fail-safe).
