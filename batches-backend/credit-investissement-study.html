Tableau d'amortissement (Annexe 68) — Entièrement absent

Complètement absent du code. Aucune entité, aucun endpoint, aucun composant Angular. Pourtant nécessaire avant le calcul de la CAF (Annexe 76).
CDC exige (Annexe 68) Tableau par période N, N+1, N+2 … N+durée amortissement :
• Famille 1 : coût retenu / durée amortissement
• Famille 2 : coût retenu / durée amortissement
• FAD : montant FAD / 5 ans (durée fixe FAD = 5 ans)
• Total = ∑ familles + FAD
Possibilité de saisir une observation.
Proposition d'implémentation 1. Entité Amortissement avec lien au schéma crédit
2. Service AmortissementCalculatorService
3. Endpoint GET /api/amortissement/{numSeqpers}/{numCanva}
4. Composant Angular amortissement/ avec table PrimeNG dynamique
Proposition — Entité + Service Amortissement
// Entité à créer @Entity @Table(name = "AMORTISSEMENT_INV") public class AmortissementInv { @Id @GeneratedValue(strategy = GenerationType.SEQUENCE, generator = "SEQ_AMORT_INV") private Long id; private Long numSeqpers, numCanva; private String idCredit; private String famille; private Integer annee; // N, N+1, N+2… private Double montant; // coûtRetenu / durée private Double montantFad; // FAD / 5 private String observation; } // Service de calcul public List<AmortissementInvDto> calculate(Long numSeqpers, Long numCanva) { List<SchemaCreditInv> schemas = repo.findWithComposants(numSeqpers, numCanva); List<AmortissementInvDto> result = new ArrayList<>(); for (SchemaCreditInv schema : schemas) { for (ComposantInv comp : schema.getComposants()) { // Montant par période = coûtRetenu / durée amortissement Double montantPeriode = comp.getMontantRetenu() / dureeAmortissement(comp.getFamille()); // FAD = montant FAD / 5 Double fadPeriode = schema.getFad() / 5.0; result.add(buildDto(comp, montantPeriode, fadPeriode)); } } return result; }
